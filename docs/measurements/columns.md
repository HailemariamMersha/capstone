# Measurement column dictionary

Generated by `npm run measurements:docs` from `scripts/measurements/columns.json`. Do not edit this generated file.

Read [the measurement guide](https://github.com/HailemariamMersha/capstone/blob/experiment/library-packet-probes/docs/measurements/guide.md) first. CSV cells are text on disk; the datatypes below describe their intended interpretation. Blank means missing/not applicable, never numeric zero. JSON can distinguish absent, null and empty string where CSV cannot. Import nanosecond decimal strings as text; spreadsheet numeric conversion loses precision.

m=measurement; s=sample; p=s.packet ?? m.packet; r=p.response; raw=s.raw ?? m.raw; n=associated context. Packet projection overrides sample fields even when a packet property is absent; see src/export/serialize.ts.

Sources are read at collection time. No library version or missing observation is inferred from the current installation. Context on samples belongs to the parent attempt. Examples are sanitized illustrations, not additional observations.
