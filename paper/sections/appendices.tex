Values retain method, target, library, outcome, units and timing. ICMP hex/base64
contains returned ICMP bytes; UDP callbacks contain application payloads. Neither
is full IP capture. JSON preserves limitations and dropped counts. The artifact's
machine-readable dictionary supplies complete column definitions. Historical
nanosecond strings retain precision; clock domains remain separate.

\subsection{Provider and policy configuration}
The configured mapping is AS14593 Starlink, AS31515 Inmarsat, AS22351 Intelsat,
AS64294 Panasonic, AS206433 SITA and AS40306 ViaSat; coverage is not independently
validated. Private AS12/AS5384 entries are TEST-labelled. Missing or over-35-day-old
ASN databases return unknown. Cached Starlink PTR names indicate egress PoPs only.

Controlled payloads use decimal bytes; allocations use MiB ($2^{20}$ bytes).
Ten 5 MB / 1 MB pairs fit inside 60 MiB. Live synchronization reserves request
bytes plus 64 KiB per response, including failures; post-trip sync is additional.
The 512 KiB batch target differs from the API's 8 MiB body limit. Separate
allocations protect probes but can leave dashboard state stale.

Compare matched observations and timing scopes. Gateway timestamps do not
isolate handset callback latency. Report signed/absolute errors, run-level
summaries and missing coverage; correlated packets are not independent flights.
Keep throughput tests sequential unless studying interference.

For added RTT $d$, apply and verify approximately $d/2$ per direction. Independent
one-way loss $p$ can yield echo nonresponse $1-(1-p)^2$; correlated loss needs
empirical treatment. Emulation is not satellite-service validation.

\section{Reproduction and Current Deliverable}
\label{app:reproduction}
APK 1.2.2/code 10 uses clean source \code{9874f99} and development signing.
The short trip collected with 1.2.1 and retried saved evidence with 1.2.2.
The 8.27 MB private long-trip bundle yields de-identified CSVs; provenance retains
input hashes and cutoff. These CSVs regenerate all five figures without private
raw records.

The main artifact source map is:
\begin{itemize}
\item \code{src/trips/}: detection, lifecycle, scheduler and trip synchronization.
\item \code{src/measurements/}: library execution, payloads and statistics.
\item \code{src/storage/}, \code{src/sync/}: persistence, batches and retries.
\item \code{android/ndt7/}: pinned fork, licensing and patch inventory.
\item \code{backend/research/}, \code{dashboard/}: owned ingestion, queries and views.
\item \code{scripts/measurements/}: analysis and shared column dictionary.
\end{itemize}

The independent UDP checker passed twenty loopback echoes using server-valid
payloads, not live accuracy validation. Priorities are pending-evidence recovery,
upload diagnosis, timestamp-validator compatibility and independent validation
before public recruitment or flight-performance claims.
